# 机器人运动学标定现场操作手册（SOP）

> 版本：1.0  
> 适用软件：`robotkinecal`  
> 适用对象：仅含旋转关节的单条串联运动链  
> 操作原则：先仿真、后实机；先验证、后部署；所有原始数据可追溯；任何时候可回滚。

本文档用于现场执行。背景原理和完整说明见 [部署与实施流程](calibration_workflow_zh-CN.md)。

## 0. 使用方法

每次标定复制一份本文档到项目记录目录，并填写所有 `<待填写>` 项。只有上一阶段的“放行条件”全部满足，才能进入下一阶段。

建议项目目录：


### B2. 眼在手外的数据转换

末端安装标定板、相机固定时：

```text
Base_T_EE = Base_T_Camera · Camera_T_Board · inverse(EE_T_Board)
```

当前仓库不分别估计 `Base_T_Camera` 和 `EE_T_Board`。任务单必须在以下模式中二选一：

```text
模式 A：机器人本体标定
输入 Base_T_EE；需要已知外参；结果可用于评估原机器人 URDF。

模式 B：相机到目标的复合标定
直接输入 Camera_T_Target；不要求预先手眼标定；结果仅表示
q → Camera_T_Target，不得作为原机器人 Base/EE 几何回写 URDF。
```

如果本次目标明确是“标定到 Board/Marker/Tracker 坐标系”，可以使用 `Base_T_Target` 作为观测，但必须在任务单中把标定末端记为 Target。部署时应把 Target 建成 `ee_name` 的固定子 link；不得把 Target 安装偏移误写为原末端 link 的几何修正。执行以下测试确认固定目标偏移行为：

```bash
python Examples/FixedTargetFrameComparison.py
```

### B3. 外参现场核验

本步骤仅适用于需要把视觉观测转换成 `Base_T_EE`、恢复机器人本体参数或更新原始 URDF 的模式。若只标定 `q → Camera_T_Target` 复合映射，可跳过 Base–Camera 和 EE–Target 外参核验，但必须核对复合观测的坐标定义和固定安装关系。

至少选择 3 个相距较远且方向不同的机器人姿态：

1. 记录编码器关节角；
2. 计算名义 `Base_T_EE`；
3. 通过相机链计算观测 `Base_T_EE`；
4. 检查两者的误差量级和变化连续性；
5. 人工移动标定板或相机后，确认系统能够检测外参失效。

禁止仅在一个姿态下验证变换方向，因为错误的逆变换可能在特殊姿态下看似合理。

### B4. 静态重复性测试

本项是推荐的测量系统质量检查，不是仓库求解器的强制前置条件。机器人固定不动，快速检查采集 20～30 帧，常规检查采集 30～50 帧；正式验收或分析时间抖动时可采集 50～100 帧，或覆盖 5～10 秒，并记录：

| 指标 | 实测值 | 项目上限 | 通过 |
|---|---:|---:|---|
| 位置标准差 [mm] | `<待填写>` | `<待填写>` | `<是/否>` |
| 姿态标准差 [deg] | `<待填写>` | `<待填写>` | `<是/否>` |
| 最大重投影误差 [px] | `<待填写>` | `<待填写>` | `<是/否>` |
| 丢帧率 [%] | `<待填写>` | `<待填写>` | `<是/否>` |

项目上限必须在采集前确定，不能根据结果事后放宽。

连续帧可能具有时间相关性，因此不应把帧数直接当作独立样本数。该测试用于评估单个静止姿态的测量重复性，不能代替运动学标定所需的不同关节配置。如果项目没有单独的测量系统验收要求，可以跳过本项；但当最终精度不达标时，应补做该测试，以区分测量噪声与运动学模型误差。

## 5. 阶段 D：实机采集计划

### D1. 样本数量

对于 6～7 自由度单臂和完整位姿观测，采用“首批采集—预求解—按诊断增采”，不要把固定数量当作验收条件：

```text
首批标定集：20～30 个高质量、充分激励的有效姿态
每轮增采：10～20 个针对弱方向设计的姿态
常规视觉最终参考：50～100 个有效姿态
高质量动捕/激光跟踪最终参考：20～40 个有效姿态
高噪声或遮挡场景最终参考：80～150 个有效姿态
验证集：15～30 个独立姿态（高噪声场景可增至 20～40）
额外候选：计划数量的 20%，用于补偿拒绝样本
```

仅位置观测建议从 30～60 个开始；常规视觉通常需要 60～120 个，高噪声场景可达到 100～200 个。7 自由度完整位姿和仅位置观测的计数下限虽然分别只有 6 和 11，但不应作为实机正式标定数量。

停止增采必须同时满足：回归矩阵满列秩；条件数相对前一批没有异常恶化；独立验证误差达到项目阈值；继续增加样本后，验证误差和参数结果趋于稳定。条件数经验区间 `< 100`、`100～1000`、`> 1000` 只能作为良好、谨慎、重点排查的参考，不是跨模型通用硬阈值。

解释规则：样本低于理论下限或回归矩阵秩亏时属于“不可唯一求解”；刚好满秩但条件数较大、子集结果波动明显时属于“可以计算但精度和稳定性不足”。增加充分激励的独立姿态可降低随机误差，重复相似姿态或同一姿态的连续帧不能替代工作空间覆盖，也不能消除外参、同步、尺寸等系统误差。

## 7. 阶段 F：数据处理

### F1. 原始数据冻结

```bash
find config raw -type f -print0 \
  | sort -z \
  | xargs -0 sha256sum > logs/raw_checksums.txt
```

原始目录设置为只读或复制为不可修改归档。所有清洗和转换都输出到 `processed/`。

### F2. 转换为求解输入

最终数据必须是：

```python
joint_positions = [q_1, q_2, ...]       # 每项长度等于关节数，rad
observed_ee_poses = [Base_T_EE_1, ...]  # spatialmath.SE3，位置单位 m
```

眼在手外转换：

```python
base_T_ee = base_T_camera * camera_T_board * ee_T_board.inv()
```

### F3. 自动质量检查

处理脚本至少检查：

- 两个列表非空且长度相同；
- 每组关节角维数正确；
- 所有数值为有限数；
- 平移量级符合机器人尺寸；
- 旋转矩阵正交且行列式接近 1；
- 相邻样本没有不合理跳变；
- Sample ID 不重复；
- 单位和外参版本一致。

### F4. 固定数据集划分

先划分再求解：

```text
标定集：70%～80%
验证集：20%～30%
```

保存 `train_indices.txt` 和 `validation_indices.txt`。不得用验证集参与参数求解。

## 8. 阶段 G：运行标定

### G1. 基础代码

```python
import roboticstoolbox as rtb

from robotkinecal import SerialRobotKineCal

robot = rtb.ERobot.URDF("config/nominal_robot.urdf")
cal = SerialRobotKineCal(
    robot,
    ee_name="<目标末端 link>",
    verbose=True,
)
cal.set_observations(train_joint_positions, train_base_ee_poses)

result = cal.solve(
    max_iterations=100,
    step_size=1.0,
    position_weight=1.0,
    orientation_weight=1.0,
    damping=1e-8,
    backtracking=True,
    min_step_size=1e-4,
)
```

### G2. 必须记录的结果

```python
last = result.iteration_results[-1]

print("termination:", result.termination_reason)
```

## 12. 故障排查速查表

| 现象 | 优先检查 | 处理 |
|---|---|---|
| 初始误差达到米级 | mm/m、变换方向、Base/Camera | 停止求解，逐项核对变换链 |
| 姿态误差接近 180° | 四元数/旋转方向、坐标轴约定 | 可视化坐标系并检查逆变换 |
| 回归矩阵秩不足 | 姿态数量和多样性 | 增加独立关节和末端方向变化 |
| 条件数很大 | 姿态集中、参数弱可观测 | 重新规划高信息量姿态 |
| `line_search_failed` | 外参、离群点、初始模型 | 检查数据，再考虑阻尼和权重 |
| 训练误差下降、验证恶化 | 过拟合、外参误差 | 增加数据，检查外参和参数约束 |
| URDF 修正达到厘米级 | 外参、单位、末端板安装 | 不部署，重新核验测量链 |
| 重复采集结果不一致 | 温漂、柔性、回差、松动 | 固定条件并分批建模/验证 |
| 某关节修正异常大 | 关节顺序、零位、可辨识性 | 检查 joint mapping 和奇异值 |
